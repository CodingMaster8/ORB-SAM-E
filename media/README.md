# media/

Shareable, presentation-ready outputs for talks, the README, and the paper —
figures, comparison videos, and the compiled validation PDF.

**The binaries here are gitignored on purpose** (figures `*.png`, videos
`*.mp4`, and `*.pdf`); only this README is tracked. The files are derived
artifacts that can be regenerated, so they are kept local rather than bloating
the repo.

## Contents (regenerated locally)

| File(s) | What it is | Generated by |
|---|---|---|
| `fig_trayectorias_ab.png`, `fig_metricas_ab.png`, `fig_rutas_odom.png`, `fig_cobertura_giros.png` | A/B figures (trajectories, metrics, odom routes, turn coverage) | `paper/figures/make_figures.py` (from `eval_runs/` results) |
| `frame_t*.png` | Sample detection/mask frames | bag overlay tools in `efficientsam3_ros2/` |
| `dyn1_filter.mp4`, `dyn2_filter.mp4` | 3-panel original \| detection \| grayout videos | `efficientsam3_ros2/efficientsam3_ros2/bag_filter_video.py` |
| `orbsame_validacion.pdf` | Compiled validation paper | `paper/orbsame_validacion.tex` |

The figures and PDF mirror `paper/figures/` and `paper/` (the `paper/` LaTeX
tree is itself gitignored). This `media/` folder is the place to drop the
specific outputs you want to share outside the LaTeX build.
